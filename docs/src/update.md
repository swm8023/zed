# Update Zed

Install each release from the build you want to use. On Windows, run `script/update-scoop-zed.cmd` from the source checkout to update the current Scoop installation. The script backs up the installed files before replacing them and reopens the project directories.

Use {#action zed::About} in the Command Palette to check the running version.
